Midnight Duo turns your own photos into a neon-night GTA 6-style cover: seven layouts headed by the default **Band** layout — a big hero photo on the left, a 2×2 stack of four more scenes on the right, and the title stacked over the hero's lower half (city line, heavy outlined block letters, yellow tagline, plus a sash, a starburst and a NEW badge) — six colour grades including the deterministic **Poster** grade (saturation + contrast lift, five-level posterize, fixed-seed grain, vignette), original Anton + Pacifico lettering (SIL OFL, vendored), per-panel captions, drag-to-pan and scroll-to-zoom, undo/redo, and one-click PNG export in four post sizes (1080×1080, 1080×1350, 1920×1080, 1080×1920). Fully offline, vanilla JS + Canvas 2D, no network requests, no Rockstar artwork or fonts.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
